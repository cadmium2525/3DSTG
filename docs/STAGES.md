# BLOOM DIVE — ステージ構成

主人公は「光の少女」。物語の軸は **光 → 闇** への潜行（DIVE）で、面が進むほど世界から光が失われていき、最後に自分の影「影の少女」と対峙する。

## 方針（ユーザー決定）
- 全3面。1面は今の難易度（やさしめ）で良い。
- 2面・3面を作りきった後、物足りなければ **ハードモード** を追加する（弾密度・速度・ボス HP の倍率、新スペル追加などで対応できる作りにしておく）。
- ラスボスは **影の少女**（案A）。
- 残機・ボム・パワーは面をまたいで持ち越し。ミス時のボム補充（2発）は全面共通。

## 面ごとの設計

## 影の少女（ラスボス）
- 主人公の光が落とす影が実体化した存在。主人公と同じ 3D モデルを黒く反転させ、髪とリボンが影の炎のように揺れる。目は淡い赤紫に光る。
- 主人公の技（光の結界・弾幕）を闇色で模倣する。
- 演出: 戦闘中は闇が画面の端から侵食し、主人公の光の範囲だけがはっきり見える。最終スペルで主人公の光が強まり、闇を晴らして決着。
- 撃破後は短いエンディング（影が光に溶け、主人公が振り向く）→ 総合リザルト。

## 視認性のルール（暗いステージ）
- 暗い背景でも、弾は「明るい核＋色付きの縁」を必ず持たせる。
- 闇色の弾は、外側に細い発光リングを付けて背景と区別する。
- 自機の当たり判定マーカーとアイテム（星・光の玉）は全ステージ共通の見た目にする。

## 進行
1. 複数ステージの仕組み（ステージ定義データ、面ごとの背景・敵・中ボス・ボス・BGM の差し替え、面クリア→次の面、全面クリア→エンディング→総合リザルト）＋ 1面の仕上げ（道中の敵の種類と配置を増やす）
2. 2面・3面の BGM（道中・中ボス・ボス）とエンディング曲を「かなでる」で作成（1 と並行）
3. 2面の中身
4. 3面の中身（影の少女のモデルはリードが担当）
5. 通しテスト → 必要ならハードモード

## 3面「深淵」の実装メモ（`src/game/stages/stage3/`, `src/danmaku/stage3.ts`, `src/game/Ending.ts`）
- 道中 約33秒（影の欠片 → 影の手 → 影の花、遠い光が闇に呑まれる「凪」）→ 中ボス ノクス（影の剣閃 → 黒鎧の陣）→ 道中 約23秒 → WARNING
  → 影の少女（影の模倣 → 写し身の弾幕 → 影の結界 → 光喰い → 光と影の螺旋）。上手く遊んで約 145 秒。
- 闇色の弾：`SpawnParams.dark = 1`（暗い芯＋細い発光リング。描画は premultiplied 合成で、従来の弾は見た目そのまま）。
  灯り（隙間の縁・中心・最終スペルの光の腕）は通常の明るい弾。
- 闇の覆いの上に描くもの：弾・アイテム・自機マーカー（従来どおり）、雑魚のハロー（目のように光る）、中ボス／ボス全体、遠い光、残り火。
- 影の少女が闇を操作：`DARK_MOD`（Background.ts）で 光喰い は明るい範囲を縮め、最終スペルは HP に応じて広げる。撃破で闇が完全に晴れる。
  `ABYSS_LIGHT`（stage3/background.ts）で灰と花弁が光に変わる。
- エンディング（約 33 秒、タップで次の場面へ）：夜明けの星海 → カメラが前へ回り込み彼女が振り向く → 6 行の言葉 → 立ち絵に戻る → THANK YOU FOR PLAYING → 総合リザルト（エンディング曲は鳴り続ける）。
- 公平性チェック：`dev/stage3.html?fair3=1`（全パターン・組み合わせ、ボット 10/10）。
